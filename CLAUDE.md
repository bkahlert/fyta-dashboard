# FYTA Dashboard — Claude Notes

## Project context

Vue 3 + Vite app that displays FYTA plant sensor data. Stack: Vue 3, Vite, Tailwind CSS v4, DaisyUI, VueUse.

- Dev server: `npm run dev`
- Build: `npm run build`
- Entry: `src/main.js` → `src/App.vue`

The Home Assistant Lovelace dashboard work is parked in [`home-assistant/`](home-assistant/CLAUDE.md).
