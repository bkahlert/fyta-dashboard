One-time setup needed

The dashboard needs a config.js file with your FYTA API token.

1

Get your token at web.fyta.de → API Token

2

Copy the example and paste your token:

cp config.example.js config.js # edit config.js → paste your token
3

Serve locally and reload:

python3 server.py # → http://localhost:8080
